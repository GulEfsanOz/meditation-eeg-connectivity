# meditation-eeg-connectivity
EEG functional connectivity analysis of mantra-based meditation

Meditation EEG Functional Connectivity

Analysis code and supplementary materials for our poster presented at the Society for Neuroscience (SfN) 2026.

Dataset: L-FAME on Hugging Face

Analysis: MATLAB scripts for RID–Rihaczek time-frequency analysis, phase-locking value (PLV), and alpha/gamma EEG connectivity.
